## 공통

- 모델 `nai-diffusion-5-full` · `k_euler_ancestral` · 28 steps · scale 5 · UC 프리셋 3
- **화풍 태그(기존 tsunako 화풍 대신 이것만 앞에 붙여요.** 작가 태그가 섞이면 도트가 뭉개져요):
```
pixel art, limited palette, sprite, chibi, {best quality, very aesthetic}
```
  - 배경·타이틀 그림은 `chibi`, `sprite`를 빼고 `pixel art, limited palette, {best quality, very aesthetic}`
- 네거티브: `tools/nai-style.json`의 공통 네거티브 그대로
- 스프라이트는 1024×1024로 뽑으면 제가 투명 배경으로 따고, 표의 게임 크기로 최근접(nearest) 축소해서 도트가 또렷하게 맞출게요.
- 혜진 외형: `1girl, black hair, long hair, straight hair, high ponytail, amber eyes` (seed 1818011)
