# 스토리 학습 개선 진행표 (2026.11 주인님 지시, 밤샘 자동 이어쓰기)

주인님 지시: 「3장처럼 한 장씩 고치고, 끝나면 '다음엔 이것부터 이어서 할게요'라고 말할 대목을 내가 시킨 것으로 보고 스스로 이어서 해라. 일어났을 땐 모든 장이 개선돼 있게.」
→ 한 차례(턴)에 한 장씩 고치고, 커밋·푸시한 뒤 `send_later`로 1분 뒤 다음 차례를 예약한다. 이 표가 다음 차례의 기억이다(대화가 요약돼도 이 파일을 보고 이어 간다).

## 한 장을 고치는 법 (3장 `fed7268`이 본보기)
1. `@quiz`마다 그 문항(`data/qs.js` 원문·보기·정답, `data/explanations.js` clues·choices·takeaway)을 뽑아 본다. 도구: `node tools/quiz-dump.js 키…`, 장 전체 대략 점검은 `V=1 node tools/quiz-cover.js story/chNN-*.js`.
2. **정답 사실과 자료 단서가 문제 앞 이야기에 다 나왔는지** 확인한다. 사진 보기 문항은 정답 사진의 유물을 `@photo`(기출 보기 사진 이름, `data/figures.js`의 identified 이름)로 문제 앞에 보여 준다. 사진은 직접 열어 이름과 맞는지 본다.
3. 배치표(`CLAUDE.md` 「히로인 배치표」)의 히로인이 그 다이브를 이끈다. 사실은 히로인의 사정·소원·두려움·소품(장부·가보·명단…)으로 꿴다. 강의식 나열(사연이 줄줄 읊기) 대신 인물이 겪는 일로.
4. 문제 묶음 앞: 확인 선택지(`@choice`, 맞으면 `{study+1}`, 틀리면 인물이 바로잡아 줌) → 오르페이아의 짧은 단서 정리 → 인물이 **부탁**하며 `@quiz`. 묶음은 3~5문항 이하로 쪼갠다.
5. 억지 진지함(「…………」, 이유 없는 침묵, 음악 끄기) 걷어내기. 개그·러브코미디 살리기.
6. 사실은 기출 원문·해설 낱말로만. 새로 쓴 사실은 `grep`으로 대조한다(지어낸 일화 금지 — 3장에서 도림의 바둑, 나무 사자, 왕건 혼인 정책을 걸러냈다).
7. 검사: 라벨 중복·없는 점프, 문항 전체 중복(이야기 전체 한 번), `node --check`, `@cutin` 이름, 새 모브 이름은 `MOB_BY_NAME`에. 가능하면 Playwright로 `VN.chapters`에서 그 장이 파싱되는지만 본다(전체 테스트는 주인님이 원할 때만).
8. 커밋(무엇을 고쳤는지 목록) → `main`에 푸시 → 이 표의 상태를 고친다 → 다음 차례 예약.
