# 스탠딩 개선안 (2026.11, 검수 전)

새 그림은 `st2_` 이름으로 뽑는다. 본편은 `st_` 그림만 쓰므로 뽑혀도 게임 화면은 바뀌지 않는다.
검수해서 통과한 것만 적용한다.

## 무엇을 고치나

| 묶음 | 대상 | 문제 | 방법 |
|---|---|---|---|
| A 잘린 그림 | 새벽(엄마) angry·shy·teary·pregnant | 허벅지에서 잘린 반신이라 다른 표정과 키·크기가 다르다 | 전신 그림 `st_saebyeok_mom` i2i(0.55, 임신 0.72) |
| B 머리색·옷 | 다솜 smile·serious·surprised·teary | 머리가 보라색으로 샌다 | `st_dasom_angry`(검은 머리) i2i 0.6 |

| | 도담 surprised·teary | 머리색·치마가 다르다 | `st_dodam_smile` i2i 0.6 |
| | 해랑 angry·smile·surprised | 소매·장화·덧옷이 표정마다 다르다 | `st_haerang_shy` i2i 0.6 |

| | 단오·아라·쇠별 home_pregnant | 자전거, 회색 빗금, 파란 붓자국 | 소품 금지어 + 각자 home i2i |
| D 새 표정 | 한별 worry(대본 12줄), 가온 worry(4), 여울 worry(4), 소담 serious(4), 아라 pout(3) | 그림이 없어 다른 표정으로 대신 나온다 | 같은 인물 smile i2i 0.6 |

모두 33장.

## 적용하는 법(검수 뒤)

1. 통과한 그림은 `assets/st2_X.webp`를 `assets/st_X.webp`로 덮어쓴다. 옛 그림은 git 기록에 남는다.
2. `tools/nai-assets.json`에서 원래 `st_X` 항목의 prompt·init·strength를 `st2_X` 것으로 바꾸고 `st2_X` 항목은 지운다. 그대로 두면 봇이 `st2_`를 다시 뽑는다.
3. D 묶음(새 표정)은 `vn.js` `CAST`에서 그 표정이 가리키는 그림을 새 파일로 바꾼다. 예: `hanbyeol` `worry:'st_hanbyeol_worry'`.
4. 탈락한 것은 `st2_` 그림과 항목을 지운다.

## 검수 결과(2026.11.24)

- 통과 30장 → `st_`로 적용했다. 새 표정 5종(한별·가온·여울 worry, 소담 serious, 아라 pout)은 `vn.js` `CAST`에 연결했다(전에는 serious·angry·surprised·worry로 대신 나왔다).
- 새벽(엄마) 4장은 전신이 됐고, 다솜·한별은 머리색이 검게, 해랑·도담·서리는 옷이 같은 표정끼리 맞춰졌다. 달래·보리 집옷과 단오·아라·쇠별 임신 집옷의 가구·자전거·튜브·빗금은 사라졌다(달래 집옷에 노란 천, 쇠별 임신 집옷에 흰 띠 하나는 남았지만 들고 있는 소품이라 통과).
- 화선 집옷(home·home_shy·home_pregnant): 지퍼가 열린 판이라 처음엔 탈락시켰으나, 주인님이 이 판을 그대로 쓰기로 해서 적용했다(재주문 취소). 33장 모두 적용.
- 아직 2배 키우기 전 크기(832×1216)로 적용했다. 키우기는 봇이 한다.
