## 3. 놓친 것에서 배울 것 — 「단골은 쉬지 않는다」

자작문제를 만들 때 분석표의 「★최근 공백」 주제를 많이 골랐는데, 정작 81회에서는 거의 매회 나오는 단골이 그대로 나왔다. **다음 자작문제는 「출제 빈도 상위 단골은 반드시 1문항씩」 + 「최근 공백」 순서로 뽑는다.** (`tools/predicted.py`에 단골 목록 검사를 더하는 것을 권한다.)

또 하나: 우리 자작문제 94번(자작-94)의 정답 「덕대가 물주의 자금으로 광산 경영」이 실제 24번의 오답 보기로 나왔다. 「조선 후기 경제 묶음」을 통째로 알아야 하는 문제 — 판서에 묶음으로 정리해 두면 좋다.

## 5. 게임에 걸린 문제와 처리 (2026.11.28 주인님 결정: 오르페이아가 만든 문제는 「자작문제」, 회차 이름을 붙이지 않는다)

1. **키 충돌 — 처리함**: 자작문제가 `r: 81`(키 `81-N`)을 쓰고 있어 진짜 81회와 겹쳤다. 자작문제를 `r: "자작"`, 키 `자작-N`으로 옮겼다(대본 `@quiz` 48줄의 146개, `data/predicted.js`·`data/predicted-figures.js`, 그림 `assets/qfig/jajak-N.webp` 162장, `tools/predicted.py`·`quiz.js`·`vn.js`·`tools/lint.js`·`tools/quiz-dump.js`, CLAUDE.md·문서). 풀이 기록은 처음 불러올 때 `81-N` → `자작-N`으로 한 번 옮긴다(`core.js`, `records.migJajak`). 화면 이름은 「자작문제」, 모의고사는 「자작문제 모의고사」.
2. **81회 50문항 — 넣음(1차)**: `tools/src/qs81.json` → `data/qs.js`(r 81, 600문항). 기출 풀기의 「제81회」에서 풀 수 있다. 남은 일: 문항별 자세한 해설(`data/explanations.js`의 `clues·reason·choices`), 자료 그림(문제지 쪽 그림에서 잘라 `question-materials/81-N.webp`, 사진 보기 6·18·25번은 보기 그림도 잘라 이름 확인 — 지금은 자료를 글로 보여 준다), `tools/analyze.py` 다시 돌려 `docs/출제-분석.md`·`MOCK_QUOTA`를 71~81회 기준으로.
3. **이야기에 배정 — 아직**: 「한 문항은 이야기 전체에서 한 번」 규칙대로 81회 50문항을 각 장 장면에 나눠 넣는다. 같은 주제의 자작문제가 서 있던 2단계 배틀 자리부터 진짜 기출로 바꾸는 것이 자연스럽다. 81회에 처음 나온 장면(용양봉저정·강화도행렬도·남영동 대공분실·반도 호텔 등)은 그 시대 히로인 장면의 소품·배경으로 좋다.
4. **판서 보강 — 아직**: 「사이·이후」 시기 문제가 3점 문항을 휩쓸었다. 핵심 노트에 시기 경계 연표(244 관구검 → 313 낙랑 축출 → 400 신라 구원 / 1173 김보당 → 1196 봉사 10조 → 1258 최의 제거 / 1904.1 국외 중립 → 1904.2 한일 의정서 / 1907 신협약 → 1908 서울 진공 → 1910 경찰권 / 1996 OECD → 1998 금 모으기 → 2007 한미 FTA)를 더한다.
5. **미니게임 데이터 — 아직**: 「먼저일까?」·「연표 꿰기」 사건 목록(`data/minigames.js`)에 위 시기 경계 사건을 더하면 그대로 3점 문항 연습이 된다.
