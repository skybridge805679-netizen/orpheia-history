# 자료 형식 분포 (기출 550 vs 오르페이아 예상 160)

`node tools/formats.js`가 만든 표다. 낱말 규칙으로 나눈 대략값이고, 예상 문제는 모두 진행자가 자료를 소개하는 틀(FRAME/SCENE)이라 '해설사 말풍선'·'사진' 칸은 자료 안쪽 틀 기준으로만 셌다.

새 예상 문제를 만들 때는 기출 비율보다 많이 쓴 틀(가상 대화·신문·AI)보다, 덜 쓴 틀(모둠 발표·교사 문답·탐구 계획서·답사·전시·강좌·분야별 표·학습지·지도)을 먼저 고른다. 틀 함수는 `tools/predicted.py`의 MODUM·QA·SHEET·TAMGU·DAPSA·POSTER·LECTURE·FIELDS.
