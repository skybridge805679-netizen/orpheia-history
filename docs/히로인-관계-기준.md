# 히로인 관계 기준

2026.11 주인님 지정
- 「연표 다이브에서 처음 만나는 달래와의 관계를 아주 진하게. 첫 단추를 잘 끼워야 뒷내용도 이런 식으로 하면 되겠다는 기준이 생긴다.」
- 「관계 기준을 한 틀로 정하면 히로인별로 다양한 러브스토리가 나오기 힘들다.」

## 0. 획일화 경계(2026.11 주인님 지적, 두 번)
- 「히로인이 그 사실 때문에 직접 곤란해진다」「역사가 그 사람의 두려움을 건드린다」 같은 **한 히로인에게 맞았던 방식을 모든 히로인의 필수 조건으로 올리지 않는다.** 그렇게 하면 이름만 다른 같은 이야기가 된다.
- 장을 고칠 때 「기준 몇 개를 채웠나」로 세지 않는다. 그 사람의 설정(`docs/인물-설정.md`)에서 출발해 **그 사람에게만 어울리는 이야기**를 먼저 정하고, 앞뒤 장과 겹치는지만 본다.
- 2장 달래의 일곱 마디, 3장 작업 때 뽑은 「곤란해지기·확인 선택지·부탁 출제」 세 가지는 그 장에 맞았던 **사례**일 뿐 기준이 아니다.
- **문제를 여는 말, 맞힌 뒤의 말도 돌려쓰지 않는다.** 예전 일괄 작업이 「자, 그럼 방금 이야기를 하나씩 짚어 봅시다」「같이 맞춰 봐요. 방금 들은 그대로요!」「……됐소. 제대로 아는구려」「어, 사연 님?! ……네, 맡길게요」 같은 문장을 말하는 사람만 바꿔 190번 남짓 박아 두었다(2026.11에 모두 장면마다 다른 말로 고침). 새 문장을 쓸 땐 그 장면의 소품·직업·사정에서 말을 꺼낸다(편지, 호외, 점호, 받아쓰기, 탁본, 주먹밥 보따리 …). 확인: `cat story/ch*.js | grep "^\[" | sed 's/^\[[^]]*\] *//' | sort | uniq -c | sort -rn | head` 에서 3번 넘게 나오는 문장이 없어야 한다.
- 같은 상황 장치도 이웃 장에서 되풀이하지 않는다. 예: 「첩자로 몰린다」가 4·6·7장에 연달아 있던 것을 6장(관청 이름표 소동)·7장(미끄러진 군량 수레)으로 바꿨다.

## 1. 모든 장이 지킬 것 — 주인님이 정한 것만
- 문제는 알려 준 다음 풀게 한다(CLAUDE.md).
- 재미가 먼저다(CLAUDE.md).
- 다이브 장면은 그 시대 히로인이 이끈다(히로인 배치표).
- 호감도는 선택지로 쌓이게 쓴다(무조건 `@add`만 두지 않는다, CLAUDE.md 엔딩 항목).
이것 말고는 장마다, 히로인마다 다르게 간다.

## 2. 히로인마다 달라야 하는 것
아래 축에서 이웃 히로인(같은 장, 앞뒤 장)과 되도록 많이 다르게 잡는다. 목록은 예시일 뿐, 목록에 없는 길이 더 좋으면 그쪽으로 간다.

| 축 | 고를 수 있는 것(예) |
|---|---|
| 곡선 모양 | 서서히 스며듦 / 첫눈에 / 적대에서 신뢰로 / 가짜에서 진짜로 / 여러 장에 걸친 재회 / 시간차(한쪽만 늙음) / 처음부터 한쪽이 직진 |
| 주도권 | 히로인이 끈다 / 상철이 다가간다 / 둘 다 모른 척 / 셋째 인물(가족·자매·오르페이아)이 엮는다 |
| 속도 | 한 장에 끝남 / 여러 장에 나눠 쌓임 / 한 번에 터짐 |
| 갈등의 원인 | 시대 사건 / 신분·제도 / 그 사람의 성격 / 상철이 떠날 손님이라는 것 / 연적 |
| 꽁냥 방식 | 사고(럭키스케베) / 일을 같이 함 / 돌봄 / 말싸움 / 비밀 공유 / 가르치고 배우기 |
| 고백의 형태 | 말로 / 말 대신 물건으로 / 남의 말을 빌려서 / 끝까지 안 하고 / 상철이 먼저 |
| 이별의 결 | 웃으며 보냄 / 붙잡음 / 따라가겠다고 함 / 기다리겠다고 함 / 다음 장에 다시 만남 |
| 학습이 들어오는 길 | 그 사람의 일·기술로(장부, 활, 통역, 대장간) / 함께 구경하는 남의 사건 / 소문·노래·놀이·내기 / 그 사람이 가르쳐 줌 / 상철이 가르쳐 줌 / 편지·신문·문서 / 오해 소동 / 말다툼 / 그 사람이 곤란해짐(달래가 쓴 길이라 이웃 장에선 피한다) |
| 문제가 열리는 방식 | 부탁 / 내기 / 시험 / 놀이 / 혼잣말에 끼어들기 / 그 사람이 틀린 걸 고쳐 주기 / 아무 핑계 없이 오르페이아가 내기 |

## 3. 2장 달래 — 한 가지 예
따라 쓰지 않는다. 다른 히로인과 겹치지 않았는지 비교할 때만 본다.
**곡선**: 동업 계약이 정으로 바뀜. **주도권**: 달래가 끈다. **갈등**: 시대 사건(왕검성 함락)이 '짐 싸기' 두려움을 건드린다(이 길은 달래 것이다). **꽁냥**: 사고와 오해 소동. **고백**: 말 대신 장부 표식으로. **이별**: 외상으로 붙잡아 둔다.

장면 흐름은 이렇다. 곡식 자루 사고 → 장부에 두건 표식 → 비어 있는 '집 표식' 칸 → 왕검성 붙박이 가게(첫 주소) → 함락, 다시 짐 싸기 → 영고 「하늘 무당」 오해와 「이 사람 내 남편이오!」(`cg_kk_dallae`) → 서옥제·족외혼 앞에서 붉어짐 → 노래값은 외상, 계약 연장. 종장 `hero_dallae`에서 첫 장이 「두건 양반 옆」으로 채워진다.

## 5. 겹침 주의(설정집에서 보이는 것)
- **'집·정착' 욕구가 셋이다.** 달래(둥지), 마루(내 집 마루), 서리(짐 싸지 않는 겨울). 욕구는 그대로 두더라도 곡선·주도권·꽁냥은 서로 다르게 간다. 위 초안에서는 달래 = 끌고 다니는 장사꾼, 마루 = 들이는 쪽, 서리 = 조용한 생활로 나눴다.
- **'계약'이 둘이다.** 달래(동업 계약)와 여울(가짜 약혼). 달래는 돈과 외상, 여울은 연기와 진심으로 갈라 둔다.
- **'장부' 소품이 둘이다.** 달래(외상 장부)와 나루(건넌 사람 장부). 나루 장부는 이름과 '건넘/머묾'만 적고, 표식 새기기나 외상은 쓰지 않는다.

## 지킬 것
- 히로인에게 없는 표정 키(예: 달래 `pout`)는 쓰지 않는다. `vn.js` `CAST`를 먼저 본다.
- 오르페이아 질투(`@cutin pout`)는 자주 써도 되지만, 질투하는 모습은 히로인마다 다르게 쓴다(1등 다툼, 증거 녹음, 「질투하면 안 되는 장면인데요」 …).
