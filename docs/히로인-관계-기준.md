# 히로인 관계 기준 — 2장 달래가 본보기

2026.11 주인님 지정: 「연표 다이브에서 처음 만나는 달래와의 관계를 아주 진하게. 첫 단추를 잘 끼워야 뒷내용도 이런 식으로 하면 되겠다는 기준이 생긴다.」
다른 히로인의 장을 쓰거나 고칠 때 이 일곱 마디를 채운다. 학습 사실과 기출 배치는 건드리지 않고, 사실을 **그 히로인의 사정**으로 꿴다.

## 일곱 마디

| 마디 | 할 일 | 2장 달래에서 |
|---|---|---|
| 1. 첫 만남 | 러브코미디 사고(CG) + 그 사람의 **겉**이 바로 드러난다. 사고 직후에 속을 살짝 비친다 | 곡식 자루 탑 붕괴 → 무릎 → 「계약합시다, 칠 대 삼」. 직전에 「나도 짐 하나로 굴러다닌 지 십 년」 |
| 2. 묶는 소품 | 둘을 묶는 소품이 생기고, 거기에 상철이 **처음으로** 새겨진다 | 나뭇조각 장부에 두건 표식. 「사람을 새기는 건 당신이 처음」 |
| 3. 속 엿보기 | 한가한 밤, 욕구가 무심코 새어 나온다. 상철의 반응을 고르게 한다 | 장 파한 모닥불. 장부 첫 장(집 표식)이 십 년째 비었다 → 선택지 |
| 4. 욕구가 이뤄질 뻔함 | 욕구가 잠깐 이뤄진다. 다음 마디에서 잃을 것을 먼저 쥐여 준다 | 위만 조선. 왕검성 장터 붙박이 가게, 기둥 표식 = 첫 주소 |
| 5. 역사가 두려움을 건드림 | 그 시대 사건(기출 사실)이 그녀의 **두려움**을 현실로 만든다. 학습 사실 = 그녀의 상처. 곁에 있는 방식을 고르게 한다 | 왕검성 함락 → 다시 짐 싸기, 매듭이 안 지어진다 → 「같이 싸자」. 노래값을 끝까지 세지 않고 「외상」으로 단다 |
| 6. 꽁냥 상승 | 그 시대 풍습·행사로 크게 웃기는 오해 소동, 그 뒤 조용한 둘만의 컷(꽁냥 CG). 혼인 풍습 앞에서 얼굴이 붉어진다 | 영고 「하늘 무당」 오해 → 「이 사람 내 남편이오!」 → 털가죽 한 장(`cg_kk_dallae`). 서옥제·족외혼에서 말하다 멈춤 |
| 7. 이별의 약속 | 소품에 남는 약속. 종장 개별 엔딩이 이것을 회수한다 | 장부 뒷장의 외상 = 계약 연장. 종장 `hero_dallae`에서 첫 장이 「두건 양반 옆」으로 채워진다 |

## 지킬 것
- 호감도 선택지는 장마다 **4개 안팎**. 셋째 보기는 오르페이아 쪽(`orp+`)으로 두어, 히로인과 오르페이아 사이에서 실제로 고르게 한다. 무조건 `@add`는 두지 않는다.
- 오르페이아 질투(`@cutin pout`)는 2~3번. 슬픈 마디(5)에서는 「질투하면 안 되는 장면인 거 아는데요」처럼 개그로 눌러 둔다. 마디 5도 재미를 빼지 않는다(「손이 그새 까먹었나 봐」).
- 히로인의 버릇(달래: `~수` 말투, 손가락 셈, 쇠칼, 장부)을 마디마다 한 번씩 쓴다.
- 히로인에게 없는 표정 키(예: 달래 `pout`)는 쓰지 않는다. `vn.js` `CAST`를 먼저 본다.
- 소품·약속은 `docs/인물-설정.md`의 속 욕구·두려움·엔딩 결에서 뽑는다. 거기 없는 것을 새로 정하면 설정집에 먼저 적는다.
